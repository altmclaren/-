# Просмотр Документов - Book Page Turner App

Современное веб-приложение для просмотра документов с эффектом перелистывания страниц книги.

## Особенности

- 📚 **Эффект книги** - Просматривайте документы с красивым 3D эффектом перелистывания страниц
- 📁 **Множественные документы** - Открывайте несколько документов одновременно с системой вкладок
- 🎨 **Drag & Drop** - Загружайте файлы простым перетаскиванием
- ⌨️ **Навигация клавиатурой** - Используйте стрелки ← → для перелистывания страниц
- 📄 **Поддержка форматов** - PDF, TXT, JPG, PNG и другие
- 🎯 **Прогресс-бар** - Отслеживайте прогресс чтения

## Запуск локально

**Требования:** Node.js

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите приложение:
   ```bash
   npm run dev
   ```

3. Откройте браузер по адресу `http://localhost:5173`

## Использование

1. **Загрузка документа**
   - Нажмите кнопку "Загрузить документ"
   - Выберите файл или перетащите его в область загрузки
   - Поддерживаются форматы: PDF, TXT, JPG, PNG

2. **Навигация по страницам**
   - Используйте кнопки ← → для перелистывания
   - Или используйте клавиши стрелок на клавиатуре
   - Прогресс-бар показывает текущую позицию

3. **Работа с вкладками**
   - Загрузите несколько документов
   - Переключайтесь между ними, кликая на вкладки
   - Закрывайте ненужные документы кнопкой ✕

## Структура проекта

```
├── components/
│   ├── BookViewer.tsx         # Компонент просмотра с эффектом книги

│   └── DocumentUploader.tsx   # Компонент загрузки файлов
├── services/
│   └── documentProcessor.ts   # Обработка различных форматов файлов
├── App.tsx                    # Главное приложение
└── index.html                 # HTML точка входа
```
